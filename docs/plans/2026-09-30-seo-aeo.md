### Phase 4: structured data (agent, 1.5 h)

One JSON-LD graph per page, with stable `@id`s, so every page points at the same Person entity. This is the biggest GEO
lever on the site: it tells crawlers who the person is, what they know, and what they offer.

#### 4a. Helper (40 min)

Create `src/utils/json-ld.ts`:

```ts
import { allProjects } from '@/content/projects';
import { capabilities, description, faq, person, siteUrl, socials } from '@/content/site';
import type { CaseStudy } from '@/content/types';

export const ids = {
  person: `${siteUrl}/#person`,
  website: `${siteUrl}/#website`,
};

const personNode = {
  '@type': 'Person',
  '@id': ids.person,
  name: person.name,
  givenName: 'Oussama',
  familyName: 'Labrahmi',
  jobTitle: person.jobTitle,
  description,
  url: siteUrl,
  email: `mailto:${person.email}`,
  // image: `${siteUrl}/images/oussama.jpg`, // Uncomment when premise P3 lands.
  address: { '@type': 'PostalAddress', addressLocality: 'Casablanca', addressCountry: 'MA' },
  alumniOf: { '@type': 'EducationalOrganization', name: '1337', url: 'https://1337.ma' },
  knowsAbout: [
    'Next.js', 'React', 'TypeScript', 'Node.js', 'Express', 'PostgreSQL', 'Drizzle ORM',
    'Datadog', 'Service level objectives', 'On-call', 'Terraform', 'Google Cloud Platform',
    'Playwright', 'Vitest', 'AI agents', 'Claude', 'Claude Code', 'n8n', 'Headless CMS',
  ],
  sameAs: socials.map((link) => link.href),
  makesOffer: capabilities.items.map((item) => ({
    '@type': 'Offer',
    itemOffered: { '@type': 'Service', name: item.title, description: item.body },
  })),
};

const websiteNode = {
  '@type': 'WebSite',
  '@id': ids.website,
  url: siteUrl,
  name: person.name,
  publisher: { '@id': ids.person },
  inLanguage: 'en',
};

export function homeGraph() {
  return {
    '@context': 'https://schema.org',
    '@graph': [
      websiteNode,
      personNode,
      {
        '@type': 'ProfilePage',
        '@id': `${siteUrl}/#profile`,
        url: siteUrl,
        mainEntity: { '@id': ids.person },
        isPartOf: { '@id': ids.website },
      },
      {
        '@type': 'FAQPage',
        '@id': `${siteUrl}/#faq`,
        mainEntity: faq.items.map((item) => ({
          '@type': 'Question',
          name: item.question,
          acceptedAnswer: { '@type': 'Answer', text: item.answer },
        })),
      },
      {
        '@type': 'ItemList',
        '@id': `${siteUrl}/#work`,
        itemListElement: allProjects.map((project, index) => ({
          '@type': 'ListItem',
          position: index + 1,
          url: `${siteUrl}/work/${project.slug}`,
          name: project.title,
        })),
      },
    ],
  };
}

export function caseStudyGraph(project: CaseStudy) {
  const url = `${siteUrl}/work/${project.slug}`;

  return {
    '@context': 'https://schema.org',
    '@graph': [
      {
        '@type': 'Article',
        '@id': `${url}#article`,
        headline: project.title,
        description: project.seoDescription ?? project.shortVersion,
        url,
        // Checked on the preview: this path returns the PNG without the ?hash query Next adds to og:image.
        image: `${url}/opengraph-image`,
        dateModified: project.updated,
        author: { '@id': ids.person },
        publisher: { '@id': ids.person },
        isPartOf: { '@id': ids.website },
        about: project.facts.client,
        keywords: project.facts.stack.join(', '),
      },
      {
        '@type': 'BreadcrumbList',
        itemListElement: [
          { '@type': 'ListItem', position: 1, name: 'Home', item: siteUrl },
          { '@type': 'ListItem', position: 2, name: 'Work', item: `${siteUrl}/#work` },
          { '@type': 'ListItem', position: 3, name: project.name, item: url },
        ],
      },
      personNode,
    ],
  };
}

/** Escapes `<` so no content string can close the script tag (see the Next.js JSON-LD guide). */
export const serializeJsonLd = (data: unknown) => JSON.stringify(data).replace(/</g, '\\u003c');
```

- Prettier will reformat the long `knowsAbout` array. Let it.

### Phase 6: llms.txt (agent, 30 min)

`llms.txt` is a plain-text summary at the site root that some AI tools read. It is cheap, generated from the same
content, and cannot drift.

- [ ] 1. Create `src/app/llms.txt/route.ts`. Read the route handler doc first (rule 5).

  ```ts
  import { allProjects } from '@/content/projects';
  import { capabilities, description, faq, person, siteUrl, socials } from '@/content/site';

  export const dynamic = 'force-static';

  export function GET() {
    const lines = [
      `# ${person.name}`,
      '',
      `> ${description}`,
      '',
      `Based in ${person.location}. Email: ${person.email}. Open to full-time roles and freelance projects, remote.`,
      '',
      '## What I do',
      ...capabilities.items.map((item) => `- ${item.title}: ${item.body}`),
      '',
      '## Case studies',
      ...allProjects.map((p) => `- [${p.title}](${siteUrl}/work/${p.slug}): ${p.card.summary}`),
      '',
      '## Questions',
      ...faq.items.flatMap((item) => [`### ${item.question}`, item.answer, '']),
      '## Profiles',
      ...socials.map((s) => `- [${s.label}](${s.href})`),
      '',
    ];

    return new Response(lines.join('\n'), { headers: { 'Content-Type': 'text/plain; charset=utf-8' } });
  }
  ```

- [ ] 3. `pnpm start`, then `curl -s http://localhost:3000/llms.txt`. Read it top to bottom. It should read like a short,
      honest résumé. No dashes, no banned words.

### Failure modes

| Failure | What happens | Guard |
| ------- | ------------ | ----- |
| `proof` slug typo | Dead link on home | `capabilities.tsx` throws at build |
| A content string contains `</script>` | Breaks page HTML | `serializeJsonLd` escapes `<` |
| `NEXT_PUBLIC_SITE_URL` set on preview deploys | Preview URLs inside JSON-LD | Previews are not indexed. Set the var for Production only |
| Article `image` path breaks | Schema points at a 404 | Path checked on the preview (200, image/png). Phase 4 re-checks on production |
| FAQ claims drift from case studies | AI engines quote a wrong fact | Phase 3 rule: answers use facts from project files only, one flagged for owner sign-off |
| Nav item wraps on phones | Broken header | Phase 3 check at 375px, remove the item if it wraps |
